## 0. How to read this document

- Every requirement is numbered `INV-nnn` and uses MUST / MUST NOT / SHOULD language. Later stages verify them one by one.
- Every disposition is one of:
  - **KEEP** — file/module is taken over unchanged except for renaming/branding (see INV-011).
  - **ADAPT** — file/module is taken over but its semantics change; the "to what" is stated.
  - **DELETE** — file/module is removed from the croco calc repo; the "why" is stated.
- **Effort** is per module for one worker: **S** = up to ~0.5 day, **M** = ~0.5–2 days, **L** = more than 2 days.
- Assumptions are labelled `ASSUMPTION` and collected in section 14. Where the brief is ambiguous this document picks the most sensible reading rather than guessing silently.
- All monkeytype paths below are relative to the reference checkout root and were opened or listed while writing this document.
