# Security Policy

We take the security and integrity of croco calc very seriously. If you have found a vulnerability,
please report it as soon as possible so we can remediate the issue quickly.

### Reporting a Vulnerability

For vulnerabilities that impact the confidentiality, integrity or availability of croco calc
services, send your disclosure by [email](mailto:contact@crococalc.com). Please do **not** open a
public GitHub issue for a security report.

For non-security platform bugs, open a normal issue on
[GitHub](https://github.com/lxorb/croco-calc/issues) instead.

Include as much detail as possible to ensure reproducibility. At a minimum, a disclosure should
include:

- Vulnerability description
- Proof of concept
- Impact
- Screenshots or other proof

### Submission Guidelines

Do not engage in activities that might cause a denial of service condition, create significant
strain on critical resources, or negatively impact users of the site outside of your own test
accounts.
